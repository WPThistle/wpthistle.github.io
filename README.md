# wp.thistle.casa

The WPThistle website, served by GitHub Pages from this repository.

- Custom domain: `wp.thistle.casa` (see the `CNAME` file)
- Cloudflare DNS: `CNAME` record, name `wp`, target `wpthistle.github.io`, DNS only (grey cloud), TTL Auto
- Plain static HTML and CSS. No build step. Edit `index.html` and push to publish.
- WPThistle Backup and Restore itself lives at https://github.com/WPThistle/wpthistle-backup-restore
