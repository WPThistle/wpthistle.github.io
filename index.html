Why this exists

Most WordPress-to-cloud backup plugins ask you to trust that a backup succeeded. This plugin never reports success until it has independently read every uploaded component back from storage and verified its SHA-256 checksum against the one recorded at archive time, with a final completion marker uploaded and verified last.

Your sites were backed up to a service you may be leaving. WPThistle backs them up to storage you control instead, and makes every backup prove itself before it is called finished.

What it does

Backups you control

Manual or scheduled backups of your database and files to a Nextcloud, ownCloud or OpenCloud server you control, over authenticated HTTPS WebDAV. Or straight to your browser with "Download Now", with zero cloud dependency.

Verified, every time

Read-back SHA-256 verification of every uploaded component before a backup is ever marked complete. Retention pruning and opt-in incremental file backups keep storage in check.

Restore and migrate

One-click restore in place, from your configured destination or from an uploaded backup bundle. The Migrate section restores a backup onto a new domain and rewrites every URL it contains to match.

Built to keep running

A non-blocking, resumable job runner that checkpoints its progress, so an interrupted backup or restore resumes instead of restarting. Notifications on success or failure across email and eight other channels.

WP-CLI support

Run backups, check status and restore from the command line with wp wpthistle-backup-restore run, status and restore.

Updates without a marketplace

A self-hosted update feed through GitHub Releases. No wordpress.org listing required, no account, no subscription.

Requirements

WordPress 6.4 or later, and PHP 8.1 or later. To use "Download Now", nothing else is needed. To back up to a Nextcloud, ownCloud or OpenCloud destination, that server needs to be reachable over HTTPS, with a dedicated, non-admin account and an app password. Do not use your main account's password.

Install

1. Download the latest release ZIP from GitHub Releases.
2. Upload and activate the plugin in WordPress.
3. Go to WPThistle > Backup and Restore.
4. Enter your destination, or skip it to use "Download Now".
5. Click "Back Up Now".

Restoring is one click from the same settings page. Tick "this backup is from a different site" if the backup came from a different domain, and every URL in it is migrated to the new site's address.

Security

The plugin has a documented threat model and has been through independent security review before shipping, with fixes re-verified. Authenticated HTTPS WebDAV transport only: no plaintext credentials and no TLS verification bypass. See the security policy for how to report a vulnerability, and the threat model for the full picture.

Multisite is not supported, and is not a planned feature.
